Decision: kit-managed files (every path in orchestration-kit.manifest.json `files`) are never hand-edited; changes go through the answers and `bash .agents/skills/agent-kit/bin/emit.sh --answers <file> --upgrade`, and `scripts/verify.sh --only kit` enforces it via sha256.

Alternatives considered: delegating the kit check to `emit.sh --upgrade --dry-run` (suggested by an evaluator) — not adopted this goal; the sha check is simpler and offline, but it duplicates emitter semantics (seedFiles), so revisit if a kit upgrade changes manifest fields.

Consequence: the feature skill's "update ORCHESTRATION.md progress" step conflicts with this — orchestration progress for goals is tracked in _memory/work/goals/<goal>/progress.md instead of the kit-managed ORCHESTRATION.md.
