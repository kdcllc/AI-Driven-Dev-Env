# Content intake procedure (articles and repos)

Ingested from the retired `.github/workflows/content-intake.yml` and its setup doc
(removed 2026-10-25 along with Squad). This is now the procedure an agent or maintainer
follows by hand (e.g. `/feature process content issue #N`, or by assigning the Copilot
coding agent to the issue).

## Trigger

An issue opened from `.github/ISSUE_TEMPLATE/content-article.yml` (label
`content:article`) or `content-repo.yml` (label `content:repo`).

## Parse the issue form

- URL: the line after `### Article URL` or `### Repository URL`; fall back to the first
  `https://…` in the body. No URL → comment asking the submitter to add one, stop.
- Category: the line after `### Category` (default `Other`).
- Context: text under `### Why is this useful?` (optional).

## Target file (slug rules)

- Article: last non-empty path segment of the URL, non `[a-z0-9-]` chars → `-`,
  lowercased, max 60 chars (`untitled` if empty) → `articles/<slug>.md`.
- Repo: `github.com/<owner>/<repo>` → `<owner>-<repo>`, lowercased, non `[a-z0-9-]` → `-`,
  max 60 chars (`unknown-repo` if not GitHub) → `repos/<slug>.md`.

## Steps

1. Read the content at the URL (web fetch for articles, GitHub API for repos).
2. Create the target file from `articles/.template.md` or `repos/.template.md`; fill every
   field accurately from the source. Keep it concise, factual, focused on relevance to
   AI-driven development.
3. Update `articles/index.md` or `repos/index.md`: add the entry under the matching
   category section (create the section if missing), keep entries alphabetical, and
   replace the `_No entries yet._` placeholder if it is the first entry.
4. Do NOT modify `articles.md` or `code.md` — they are manually curated with different
   templates.
5. Commit as `docs: add <article|repo> "<slug>"` and open a PR that references the issue
   for human review.

## Notes from the old automation

- Copilot coding agent assignment used `copilot-swe-agent[bot]` via
  `POST /repos/{owner}/{repo}/issues/{n}/assignees` with `agent_assignment`
  (needed a `COPILOT_ASSIGN_TOKEN` secret; `GITHUB_TOKEN` alone was not enough).
- Label colors used: `content:article` `1D76DB`, `content:repo` `0075CA`.
- Catalog rules (categories, review checklist) live in
  `.github/templates/CONTENT_SYSTEM_INDEX.md`.
